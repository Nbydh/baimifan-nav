# 白米饭导航 · 免费托管部署指南

本文件夹内只有两个文件：

- `index.html` —— 完整页面（v5.3 文件夹排序版，单文件、零依赖，无任何外部资源）
- `README.md` —— 本说明

目标：把起始页托管成一个长期有效的网址，手机 Via 浏览器直接打开，无需每次传文件。

---

## 重要提示：EdgeOne Pages 免费默认域名为什么不能用

腾讯云 EdgeOne Pages 的免费版默认域名，在**中国大陆网络环境**下只提供 3 小时限时预览（带 token 的链接，过期返回 401）。这是官方的内容合规策略，不是配置问题。

- 想长期使用必须绑定自定义域名
- 国内版免费版加速区域锁定「含中国大陆」，绑域名**必须 ICP 备案**
- 结论：EdgeOne 免费默认域名不适合个人长期使用，请用下面的方案

---

## 方案一（推荐）：GitHub Pages —— 免费、永久、免备案

**优点：** 永久有效、无备案、免费、稳定；国内一般可访问（速度看运营商）。

**步骤（约 5 分钟）：**

1. 注册/登录 GitHub：<https://github.com>
2. 点右上角「+」→「New repository」
3. 仓库名随意（如 `baimifan-nav`），选 **Public**，点「Create repository」
4. 进入仓库 →「Add file」→「Upload files」→ 把本文件夹里的 `index.html` 拖进去 → 点「Commit changes」
5. 仓库 **Settings → Pages**：
   - Source 选「Deploy from a branch」
   - Branch 选 `main`，目录选 `/ (root)`
   - 点「Save」
6. 等 1~2 分钟，访问 `https://你的用户名.github.io/仓库名/` 即可（如 `https://zhangsan.github.io/baimifan-nav/`）
7. 手机 Via：设置 → 起始页 → 自定义网址，填入上述地址

**以后更新页面：** 在仓库里重新上传覆盖 `index.html`，1 分钟后自动生效。

---

## 方案二（想更快 + 微成本）：买域名 + EdgeOne Pages，免备案

**优点：** 国内速度最快（香港/新加坡节点），永久稳定；**前提是加速区域能选「全球可用区（不含中国大陆）」**，官方明确该区域绑自定义域名**无需 ICP 备案**。

**步骤：**

1. 在腾讯云买一个便宜域名（`.top` / `.xyz` 首年约 ¥10~30）
2. 腾讯云控制台 → EdgeOne Pages → 创建项目 → 选「直接上传」
3. **加速区域选「全球可用区（不含中国大陆）」**（关键！选含中国大陆就必须备案）
4. 拖入 `index.html` → 开始部署
5. 项目设置 → 域名管理 → 添加自定义域名 → 按提示在域名 DNS 里加 CNAME 记录
6. 成功后用你的域名访问，长期有效

> 注意：如果创建时加速区域被锁定为「含中国大陆」，则绑域名必须 ICP 备案。免费版可能如此，那就退回方案一。

## 方案三（备选）：Cloudflare Pages

**优点：** 免费、永久、`xxx.pages.dev` 域名、免备案；国内一般能访问，速度一般（无大陆节点）。

**步骤：**

1. 注册/登录 Cloudflare：<https://dash.cloudflare.com>
2. 左侧菜单「Workers & Pages」→「Create」→「Pages」→「Upload assets」
3. 项目名随便填，把本文件夹拖进去上传
4. 部署完成后访问 `https://项目名.pages.dev/`

---

## 重要：书签数据迁移

书签保存在浏览器本地存储（localStorage），**换网址就等于换了存储位置**。迁移步骤：

1. 用旧方式打开本地 HTML → 设置（右下角 ⚙️）→「📤 导出书签」，保存 JSON 文件
2. 打开托管后的新网址 → 设置 →「📥 导入书签」→ 选择刚才的 JSON
3. 主题/背景/文字颜色等设置在新网址里重选一次即可（书签不影响）
