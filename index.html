📖 使用方法
  • 搜索：输入关键词按 回车 搜索；点击左侧按钮切换引擎（百度/谷歌/必应 等），点「添加」可添加自定义引擎（地址里用 %s 代表搜索词）。
  • 打开书签：点击图标访问对应站点；图标经 14源高清探测 自动获取并缓存，秒开无闪烁。
  • 添加书签：点末尾「＋」或页面空白处 双击，填写名称与网址；最多显示 8个，超出自动折叠，点击右上角按钮展开。
  • 编辑 / 删除书签：长按图标（不拖动即松开）进入编辑，可修改名称、网址与图标，点「🗑 删除此书签」可删除（再点「确认」）；长按拖动则是排序。
  • 文件夹：书签拖到图标中央停留可合并成文件夹；长按文件夹可重命名或删除（内容保留到主页）；打开文件夹可拖动排序，点 ✕ 或拖到底部移出。
  • 自定义图标：编辑窗口可选 自动（真实favicon）/ 文字（自定义文字+背景色+预设色板）/ 图片（上传图片）三模式。
  • 全局图标切换：设置 → 书签图标 一键切换全部书签为图标或文字显示，零网络请求秒开。
  • 主题与模式：5套主题（3纯色+2渐变），支持 跟随系统/浅色/深色。
  • 自定义背景：上传图片或图片链接设置背景，可一键清除。
  • 自定义文字颜色：主/次文字独立 HSV取色器 精细调色 + 预设色板 快捷选色，点「默认」恢复该行。
  • 时间颜色：时 / 分 / 秒分别独立取色，可一键恢复默认。
  • 布局调节：「页面整体」滑块微调内容位置，底部功能区固定。
  • 书签备份：书签可导出 JSON / 导入恢复 / 一键恢复默认。
  • 记事本(note)：网格里的「notes」大卡片，长按可拖动排序；点开打开面板：左侧「＋ 新建」管理多条笔记，右侧直接显示内容；点「✏️ 编辑」进入全屏编辑（自动适配输入法键盘），工具栏点按 H1/H2/H3/加粗/列表等格式，点「完成」保存、「取消」放弃。
  • 数据隐私：所有书签与笔记仅保存在本地，不上传任何服务器。
