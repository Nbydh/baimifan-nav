白米饭导航 是一个轻量、极简的浏览器起始页。无广告、无弹窗——愿每次打开浏览器，都能以最快的速度、最干净的方式抵达想去的地方。

✨ 设计理念

  • 极简纯净：无广告、无弹窗、无多余打扰，界面干净克制。
  • 轻量零依赖：单文件实现，不依赖任何框架，打开即用。
  • 隐私安全：所有书签与设置仅保存在浏览器本地，绝不上传服务器。
  • 自由定制：主题、背景、文字颜色、布局位置均可随心调整。

🎯 特色功能

  • 5套主题：3纯色 + 2渐变，自动适配明暗。
  • 明暗模式：跟随系统 / 浅色 / 深色 一键切换。
  • 自定义背景：上传图片或输入URL，随时清除。
  • 自定义文字颜色：主文字、次要文字独立取色，实时预览。
  • 布局调节：页面整体上下微调，底部功能固定不动。
  • 书签管理：支持 JSON 导入导出备份、一键恢复默认。
  • 多引擎搜索：百度 / 谷歌 / 必应 / 鸭鸭走 / 搜狗 一键切换，支持添加自定义引擎。

白米饭导航，愿你的每次浏览都心情舒畅 🌾

  • 搜索：输入关键词按 回车 搜索；点击左侧按钮切换引擎（百度/谷歌/必应 等），点「添加」可添加自定义引擎（地址里用 %s 代表搜索词）。
  • 打开书签：点击图标访问对应站点；图标经 14源高清探测 自动获取并缓存，秒开无闪烁。
  • 添加书签：点末尾「＋ 添加图标」或页面空白处 双击，填写名称与网址；最多显示 8个，超出自动折叠，点击右上角按钮展开。
  • 编辑书签：手机 长按 / 电脑 右键 图标进入编辑，可修改名称与网址。
  • 文件夹排序：打开文件夹后 长按 拖动图标即可排序；拖到底部「⬇️ 移出」条，可把书签移出文件夹回到主页。
  • 自定义图标：编辑窗口可选 自动（真实favicon）/ 文字（自定义文字+背景色+预设色板）/ 图片（上传图片）三模式。
  • 全局图标切换：设置 → 书签图标 一键切换全部书签为图标或文字显示，零网络请求秒开。
  • 删除书签：编辑窗口中点击「🗑 删除此书签」并再次确认，防止误删。
  • 主题与模式：5套主题（3纯色+2渐变），支持 跟随系统/浅色/深色。
  • 自定义背景：上传图片或图片链接设置背景，可一键清除。
  • 自定义文字颜色：主/次文字独立 HSV取色器 精细调色 + 预设色板 快捷选色，点「默认」恢复该行。
  • 布局调节：「页面整体」滑块微调内容位置，底部功能区固定。
  • 书签备份：书签可导出 JSON / 导入恢复 / 一键恢复默认。
  • 更新内容：页脚「📜 更新内容」查看版本更新日志。
  • 数据隐私：所有书签与设置仅保存在本地，不上传任何服务器。
